# SAHROUD | سوله دیزاینر

نسخه 0.2.0 — نمونه اولیه وب برای مدل‌سازی هندسی پارامتریک و متره مقدماتی سوله.

## اجرا
- مخزن را با GitHub Pages منتشر کنید یا فایل `index.html` را از طریق یک وب‌سرور محلی اجرا کنید.
- برای نمایش مدل سه‌بعدی اینترنت لازم است؛ Three.js و OrbitControls از CDN بارگیری می‌شوند.
- رابط فارسی و راست‌چین است و با نمایشگرهای کوچک نیز سازگاری پایه دارد.

## امکانات نسخه 0.2.0
- مدل سه‌بعدی پارامتریک با کنترل عرض دهانه، طول، ارتفاع ستون، فاصله قاب‌ها، شیب سقف و تعداد دهانه
- نماهای سه‌بعدی، روبرو و بالا؛ چرخش و بزرگ‌نمایی مدل
- نمایش شماتیک بیس‌پلیت، چهار انکربولت در هر پایه و مهاربندهای ضربدری
- محاسبه مساحت کف، ارتفاع تاج، تعداد قاب‌ها و متره هندسی مقدماتی
- ورودی وزن واحد طول اعضا و برآورد وزن فقط برای گروه‌هایی که وزن تعریف شده دارند
- محاسبه‌گر مقطع I ایده‌آل با ورودی ارتفاع، عرض بال، ضخامت جان و ضخامت بال؛ خروجی مساحت، وزن نظری و ممان دوم سطح حول دو محور
- امکان ثبت مشخصات مقطع مستقل برای ستون، رفتر و اعضای فرعی
- ذخیره پارامترها و مشخصات مقاطع در مرورگر و خروجی JSON

## روش محاسبه مقطع I
مقطع به‌صورت سه مستطیل (دو بال و یک جان) و با چگالی مفروض فولاد 7850 kg/m³ محاسبه می‌شود. شعاع گوشه‌ها، جوش، تلرانس ساخت، خوردگی و اثرات موضعی لحاظ نشده‌اند. این محاسبه برای برآورد نظری اولیه است و جایگزین جدول معتبر سازنده یا کنترل مهندسی نیست.

## محدودیت‌های مهندسی مهم
این نسخه تحلیل سازه، بارگذاری آیین‌نامه‌ای، طراحی اعضا، کنترل کمانش و خیز، طراحی اتصالات، طراحی واقعی بیس‌پلیت و انکربولت و طراحی فونداسیون را انجام نمی‌دهد. هندسه و وزن‌ها مقدماتی‌اند و خروجی این نسخه مبنای ساخت، خرید قطعی مصالح یا صدور نقشه اجرایی نیستند. تمام نتایج باید توسط مهندس سازه و بر اساس محل پروژه، آیین‌نامه معتبر و مشخصات واقعی مصالح بررسی شوند.

## مسیر توسعه
1. اصلاح و تکمیل متره طولی هر گروه عضو و هندسه مهاربندی
2. افزودن کتابخانه مستند مقاطع استاندارد و پروفیل‌های ساخته‌شده
3. بارگذاری و تحلیل قاب با روش عددی قابل راستی‌آزمایی
4. کنترل اعضا و طراحی اتصالات مطابق آیین‌نامه منتخب
5. خروجی PDF، Excel و DXF
