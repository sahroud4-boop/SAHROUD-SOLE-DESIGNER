# SAHROUD | سوله دیزاینر

نسخه توسعه: **0.7.0** — نرم‌افزار وب فارسی برای مدل‌سازی سه‌بعدی پارامتریک سوله و متره هندسی مقدماتی.

## اجرا
- فایل `index.html` را از طریق یک وب‌سرور محلی اجرا کنید یا مخزن را با GitHub Pages منتشر کنید.
- مدل سه‌بعدی از Three.js و OrbitControls روی CDN استفاده می‌کند؛ برای بارگذاری کتابخانه‌ها اتصال اینترنت لازم است.
- رابط فارسی و راست‌چین است.

## امکانات فعلی
- مدل سه‌بعدی پارامتریک سوله چنددهانه با کنترل عرض دهانه، طول، ارتفاع ستون، فاصله قاب‌ها، شیب سقف، تعداد دهانه و فاصله لاپه‌ها
- کنترل دوربین، چرخش، بزرگ‌نمایی و نماهای سه‌بعدی، روبه‌رو و بالا
- نمایش شماتیک پای ستون، پدستال، بیس‌پلیت و انکربولت‌های پیرامونی با امکان انتخاب 4، 6 یا 8 بولت
- ورق‌های شماتیک اتصال رفتر به ستون و ورق‌های وصله تاج در مدل سه‌بعدی
- متره مقدماتی ستون‌ها، رفترها، لاپه‌ها، بیس‌پلیت‌ها، انکربولت‌ها، ورق‌های اتصال و پیچ‌های مفهومی
- محاسبه وزن اعضا با وزن واحد طول ورودی کاربر و محاسبه وزن هندسی ورق‌های اتصال با چگالی فرضی فولاد 7850 kg/m³
- محاسبه‌گر مقطع I ایده‌آل جوش‌شده شامل سطح مقطع، وزن واحد طول و ممان‌های دوم سطح حول محورهای اصلی
- ذخیره پارامترهای پروژه در مرورگر و خروجی JSON

## فرض‌ها و محدودیت‌های مهندسی
- تمام ورق‌های اتصال رفتر–ستون و وصله تاج در نسخه 0.7.0 صرفاً هندسه شماتیک برای نمایش و متره مفهومی هستند؛ ابعاد، ضخامت، تعداد و آرایش پیچ‌ها هنوز طراحی‌شده یا قابل اتکا برای ساخت نیستند.
- تعداد پیچ‌های اتصال، شمارش مفهومی اولیه است؛ قطر، رده مقاومتی، فاصله‌گذاری، فاصله از لبه، سوراخ استاندارد/لوبیایی و کنترل لغزش یا اتکایی باید در ماژول طراحی اتصال تعیین شوند.
- بیس‌پلیت، انکربولت و پدستال نمایشی هستند. کنترل خمش صفحه، سخت‌کننده، جوش، کشش و برش بولت، اندرکنش نیروها، شکست بتن، بیرون‌کشیدگی و طراحی فونداسیون انجام نمی‌شود.
- چیدمان 4/6/8 انکربولت الگوی نمایشی پیرامونی است و آرایش واقعی باید از طراحی اتصال تعیین شود.
- وزن اعضای اصلی تنها در صورت ورود وزن واحد طول توسط کاربر محاسبه می‌شود. وزن ورق‌های اتصال بر اساس ابعاد شماتیک ثابت و چگالی فرضی فولاد محاسبه می‌شود؛ پرت، جوش، پیچ و متعلقات دیگر در وزن لحاظ نشده‌اند.
- لاپه‌ها و مهاربندها هندسی/شماتیک هستند و طراحی ظرفیت، پایداری و اتصالات آنها انجام نشده است.
- مقطع I به‌صورت سه مستطیل ایده‌آل محاسبه می‌شود؛ شعاع گوشه‌ها، جوش، تلرانس ساخت و خوردگی لحاظ نشده‌اند.

## مواردی که هنوز پیاده‌سازی نشده‌اند
1. کتابخانه مستند مقاطع استاندارد و مشخصات سازندگان
2. طراحی عددی اتصال رفتر–ستون، وصله تاج، ورق بادبند، پیچ و جوش
3. طراحی و کنترل واقعی بیس‌پلیت و انکربولت
4. بارگذاری، تحلیل قاب، کنترل اعضا، کمانش و خیز مطابق آیین‌نامه منتخب
5. طراحی فونداسیون و کنترل ژئوتکنیکی
6. نقشه‌های ابعادی کامل و خروجی معتبر DXF، PDF و Excel
7. گزارش محاسبات قابل بازبینی و ردیابی فرضیات

## هشدار استفاده
این نرم‌افزار در وضعیت فعلی ابزار مدل‌سازی و متره مقدماتی است. خروجی آن مبنای ساخت، خرید قطعی مصالح یا صدور نقشه اجرایی نیست. طراحی نهایی باید با اطلاعات محل پروژه، بارهای واقعی، آیین‌نامه معتبر و بررسی مهندس سازه انجام شود.
