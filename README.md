# SAHROUD | سوله دیزاینر

نسخه 0.3.0 — نمونه اولیه وب برای مدل‌سازی هندسی پارامتریک و متره مقدماتی سوله.

## اجرا
- مخزن را با GitHub Pages منتشر کنید یا فایل `index.html` را از طریق یک وب‌سرور محلی اجرا کنید.
- برای نمایش مدل سه‌بعدی اینترنت لازم است؛ Three.js و OrbitControls از CDN بارگیری می‌شوند.
- رابط فارسی و راست‌چین است.

## امکانات نسخه 0.3.0
- مدل سه‌بعدی پارامتریک با کنترل عرض دهانه، طول، ارتفاع ستون، فاصله قاب‌ها، شیب سقف و تعداد دهانه
- ورودی فاصله هدف لاپه‌های سقف؛ تعداد ردیف‌های لاپه و طول تقریبی آنها از هندسه سقف برآورد می‌شود
- چیدمان شماتیک لاپه‌ها در امتداد طول سوله روی دو شیب هر دهانه
- نماهای سه‌بعدی، روبرو و بالا؛ چرخش و بزرگ‌نمایی مدل
- نمایش شماتیک بیس‌پلیت، چهار انکربولت در هر پایه و مهاربندها
- محاسبه مساحت کف، ارتفاع تاج، تعداد قاب‌ها و متره هندسی مقدماتی
- محاسبه وزن تقریبی برای گروه‌هایی که وزن واحد طول به آنها اختصاص داده شده است
- محاسبه‌گر مقطع I ایده‌آل و تعریف مستقل مقطع محاسباتی برای ستون، رفتر و اعضای فرعی
- ذخیره پارامترها در مرورگر و خروجی JSON

## فرض‌ها و محدودیت‌های متره
- تعداد قاب‌ها از تقسیم طول بر فاصله هدف قاب‌ها و گرد کردن رو به بالا به دست می‌آید؛ فاصله واقعی قاب‌ها برای پوشش طول برابر می‌شود.
- لاپه‌ها با فاصله هدف تنظیم‌شده و در دو سطح شیبدار هر دهانه مدل می‌شوند. این تعداد، طرح اولیه هندسی است و باید با بارگذاری، ظرفیت مقطع، وصله‌ها و جزئیات اجرایی کنترل شود.
- مقطع I به‌صورت سه مستطیل ایده‌آل و با چگالی فرضی فولاد 7850 kg/m³ محاسبه می‌شود؛ شعاع گوشه‌ها، جوش، تلرانس ساخت و خوردگی لحاظ نشده‌اند.
- طول‌ها و وزن‌ها در این نسخه برآورد مقدماتی هستند؛ تمام اجزای واقعی از جمله ورق‌های اتصال، سخت‌کننده‌ها، پیچ‌ها، جوش‌ها، پرت و وصله‌ها کامل متره نشده‌اند.

## محدودیت‌های مهندسی مهم
این نسخه تحلیل سازه، بارگذاری آیین‌نامه‌ای، طراحی اعضا، کنترل کمانش و خیز، طراحی واقعی اتصالات، بیس‌پلیت، انکربولت و فونداسیون را انجام نمی‌دهد. خروجی این نسخه مبنای ساخت، خرید قطعی مصالح یا صدور نقشه اجرایی نیست. نتایج باید توسط مهندس سازه و بر اساس محل پروژه، آیین‌نامه معتبر و مشخصات واقعی مصالح بررسی شوند.

## مسیر توسعه
1. تکمیل متره اعضای اصلی، مهاربندهای سقف و دیوار و اجزای اتصال
2. افزودن کتابخانه مستند مقاطع استاندارد
3. بارگذاری و تحلیل قاب با روش عددی قابل راستی‌آزمایی
4. کنترل اعضا و طراحی اتصالات مطابق آیین‌نامه منتخب
5. خروجی PDF، Excel و DXF
