# SAHROUD | سوله دیزاینر

نسخه 0.4.0 — نمونه اولیه وب برای مدل‌سازی هندسی پارامتریک و متره مقدماتی سوله.

## اجرا
- مخزن را با GitHub Pages منتشر کنید یا فایل `index.html` را از طریق یک وب‌سرور محلی اجرا کنید.
- برای نمایش مدل سه‌بعدی اینترنت لازم است؛ Three.js و OrbitControls از CDN بارگیری می‌شوند.
- رابط فارسی و راست‌چین است.

## امکانات نسخه 0.4.0
- مدل سه‌بعدی پارامتریک چنددهانه با تنظیم عرض دهانه، طول، ارتفاع ستون، فاصله قاب‌ها، شیب سقف و تعداد دهانه
- تنظیم فاصله هدف لاپه‌های سقف و متره هندسی تقریبی آنها
- مدل شماتیک مهاربندی سقف و دیوار
- جزئیات پارامتریک پای ستون: طول، عرض و ضخامت بیس‌پلیت؛ تعداد انکربولت (4، 6 یا 8)؛ قطر اسمی و طول مهاری نمایشی
- بازسازی هندسه اتصال با تغییر ورودی‌ها و ثبت تعداد و ابعاد ورودی در جدول متره
- محاسبه‌گر مقطع I ایده‌آل و مشخصات مستقل برای ستون، رفتر و اعضای فرعی
- ذخیره پارامترها در مرورگر و خروجی JSON

## فرض‌ها و محدودیت‌های متره
- ابعاد بیس‌پلیت، قطر و طول مهاری انکربولت، و تعداد بولت‌ها ورودی‌های هندسی کاربر هستند. مدل، کنترل مقاومت صفحه، خمش، جوش، کشش/برش انکربولت، فاصله لبه، مخروط شکست بتن، بیرون‌کشیدگی، اندرکنش و جزئیات مهاری را انجام نمی‌دهد.
- چیدمان 4/6/8 بولت صرفاً الگوی نمایشی پیرامونی است و آرایش واقعی باید از طراحی اتصال تعیین شود.
- تعداد قاب‌ها از تقسیم طول بر فاصله هدف قاب‌ها و گرد کردن رو به بالا به دست می‌آید؛ فاصله واقعی قاب‌ها برای پوشش طول برابر می‌شود.
- لاپه‌ها و مهاربندها در این نسخه به‌صورت هندسی/شماتیک مدل می‌شوند؛ طراحی ظرفیت و پایداری آنها انجام نشده است.
- مقطع I به‌صورت سه مستطیل ایده‌آل و با چگالی فرضی فولاد 7850 kg/m³ محاسبه می‌شود؛ شعاع گوشه‌ها، جوش، تلرانس ساخت و خوردگی لحاظ نشده‌اند.
- وزن اعضا فقط برای گروه‌هایی محاسبه می‌شود که وزن واحد طول آنها توسط کاربر وارد شده باشد. طول و وزن فعلی، متره اجرایی کامل نیست.

## محدودیت‌های مهندسی مهم
این نسخه تحلیل سازه، بارگذاری آیین‌نامه‌ای، طراحی اعضا، کنترل کمانش و خیز، طراحی واقعی اتصالات، بیس‌پلیت، انکربولت و فونداسیون را انجام نمی‌دهد. خروجی این نسخه مبنای ساخت، خرید قطعی مصالح یا صدور نقشه اجرایی نیست. نتایج باید توسط مهندس سازه و بر اساس محل پروژه، آیین‌نامه معتبر و مشخصات واقعی مصالح بررسی شوند.

## مسیر توسعه
1. تکمیل متره مستقل مهاربندها و اجزای اتصال
2. افزودن کتابخانه مستند مقاطع استاندارد

4. کنترل اعضا و طراحی اتصالات مطابق آیین‌نامه منتخب
