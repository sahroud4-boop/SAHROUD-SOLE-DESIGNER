# SAHROUD | سوله دیزاینر

نسخه آغازین نرم‌افزار تحت وب برای مدل‌سازی هندسی پارامتریک سوله.

## اجرا
- مخزن را با GitHub Pages منتشر کنید یا فایل `index.html` را از طریق یک وب‌سرور محلی اجرا کنید.
- برای نمایش مدل سه‌بعدی اتصال اینترنت لازم است؛ Three.js و OrbitControls از CDN بارگیری می‌شوند.
- کنترل‌ها: عرض دهانه، طول، ارتفاع ستون، فاصله قاب‌ها، شیب سقف و تعداد دهانه.

## امکانات نسخه 0.1.0
- رابط فارسی و راست‌چین
- مدل سه‌بعدی پارامتریک و نماهای روبرو، بالا و سه‌بعدی
- محاسبه مساحت، ارتفاع تاج، تعداد قاب‌ها و متره هندسی مقدماتی
- ذخیره پارامترها در مرورگر و خروجی JSON

## محدودیت مهندسی
این نسخه صرفاً نمونه اولیه مدل‌سازی و متره هندسی است. تحلیل سازه، طراحی اعضا، کنترل کمانش و خیز، بارگذاری آیین‌نامه‌ای، طراحی اتصالات، بیس‌پلیت و انکربولت و طراحی فونداسیون هنوز پیاده‌سازی نشده‌اند. خروجی این نسخه مبنای ساخت یا خرید مصالح نیست.

## مسیر توسعه
1. تکمیل مدل و اجزای سازه‌ای، شامل نمایش شماتیک بیس‌پلیت و انکربولت
2. کتابخانه مقاطع و متره وزنی تفصیلی
3. بارگذاری و تحلیل قاب
4. کنترل اعضا و طراحی اتصالات مطابق آیین‌نامه منتخب
5. خروجی PDF، Excel و DXF
